Usa el código con precaución.(Espera a que termine de procesar todas las imágenes y recursos al 100%).🚀 Paso 2: Subir los cambios a GitHubUna vez que Pygbag termine, escribe estos tres comandos (uno por uno, dándole Enter a cada línea) para enviar la actualización a internet:bash# 1. Registra todas las modificaciones de tu código y la carpeta web
git add .

# 2. Guarda el cambio con una descripción de lo que modificaste
git commit -m "Actualizacion del juego con nuevos cambios"

# 3. Sube todo a los servidores de GitHub
git push origin main
